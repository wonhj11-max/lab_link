# 논문 검토 작업 인계

2026-09-25 제품 방향 변경: 운영자가 조사·검증·저장하고 일반 사용자는 공개 논문을 열람한다. 새 논문 서비스의 계획·구현·조사는 PAPER_PUBLICATION_GUIDELINES.md를 먼저 읽는다. 새 지침과 기존 PAPER_REVIEW_RUNBOOK.md가 충돌하면 새 지침을 우선한다. Astra 계획/Sol 실행 인계 요청문은 새 지침 마지막 절에 있다. 가이드 작성만으로 실행 권한이 발생하지 않는다.

논문 검토·승인·저장 요청을 받으면 먼저 PAPER_REVIEW_RUNBOOK.md를 읽는다.
문서는 방법 수립만 완료된 상태이며 작성 자체는 실행 권한이 아니다.
사용자가 실행을 요청하면 체크포인트를 사용해 한 연구실·한 연도·10건 이하 단위로 순차 수행한다.
공식 연구실 출판 목록과 독립 논문 출처를 확인하지 않은 후보는 승인하지 않는다.
사용자 검토 투표를 대리 생성하지 않는다. 검증된 후보의 공개는 운영자 승인 RPC로 처리한다.
